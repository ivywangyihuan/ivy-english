# Ivy English · Subject Color Scope Rule v1

Status: **FROZEN**

This rule supplements the Study Journal Design Specification and overrides any older wording that treated subject-soft colors as general stationery accents.

## Core rule

Listening / Speaking / Reading / Writing colors are **semantic subject identity**, not general decoration.

Both the strong color and the soft paper color are subject colors:

- Listening: `#009B9F` + `#D6FFF7`
- Speaking: `#FF5DB1` + its light pink paper mix
- Reading: `#63C94A` + `#E8FFD8`
- Writing: `#3F63F2` + `#E9D8FF`

They may appear only when a component clearly represents that subject, such as:

- a Listening / Speaking / Reading / Writing entry card
- a subject-specific workspace
- a subject-specific CTA or focus timer
- a subject-specific progress series or score
- a question / record whose subject identity is materially relevant

They must **not** be used to decorate generic or cross-subject surfaces, including:

- Progress overview summary statistics
- Library summary / generic material cards
- Settings
- generic tabs, filters and navigation
- cross-subject history / collections
- generic action buttons
- generic paper shadows, textures, tape or decorative tabs

## Neutral-page palette

Generic and cross-subject surfaces may use only the existing neutral system:

- Paper Cream `#FFF9F0`
- Clean Paper `#FFFCF7`
- Deep Ink `#17306D`
- Butter Yellow `#FFF3A6`
- Peach Tape `#FFD4B5`
- Grid Line `#BFD5FF`
- Strong Grid Line `#92B7FF`
- Body Ink `#1F2340`

No new decorative HEX values should be invented for a single page.

Visual variety on neutral pages should come from **paper construction** — grid, ruled paper, receipt, index tabs, filing edges, tape placement and hierarchy — rather than borrowing subject colors.
